### Q4. `sc-003` — 單選題

**題目 ID**: `sc-003`

難度: `medium` ｜ 建議作答時間分類: `agile_scenario` ｜ 版本標籤: `pmbok8` ｜ 原始 performanceDomain: `Governance` ｜ ECO domain: `Process`

**題幹**

- EN: A project manager joins an organization that uses a directive PMO. The PMO mandates the methodology and templates to be used, assigns project managers to projects, and requires project managers to report progress directly to the PMO. This project manager would prefer to use a different delivery approach. What should the project manager do?
- 中: 一位專案經理加入一個採用指導型 PMO(Directive PMO)的組織。該 PMO 強制規定必須使用的方法論與範本,負責指派專案經理到各專案,並要求專案經理直接向 PMO 回報進度。這位專案經理比較希望採用不同的交付方法。這位專案經理應該怎麼做?

**選項**

- (a) Use the preferred approach, since the project manager is accountable for delivery. / 採用自己偏好的方法,因為專案經理對交付成果負最終責任。
- (b) Follow the mandated methodology, since this PMO directs the project and the project manager reports to it. / 遵循被強制規定的方法論,因為這個 PMO 直接主導專案,且專案經理須向其回報。 ✅ **正解**
- (c) Adopt the mandated templates but apply the preferred delivery approach wherever possible. / 採用被規定的範本,但盡可能在能夠的地方套用自己偏好的交付方法。
- (d) Request that the PMO grant an exception for this particular project. / 請求 PMO 為這個專案特別給予例外許可。

**詳解**

指導型 PMO(Directive PMO)會直接指派專案經理、強制規定方法論,並要求專案經理向其回報,代表 PMO 對專案握有直接控制權。在這種情境下,專案經理應在 PMO 訂定的框架內執行,而非以個人偏好取代組織規定。這是三種 PMO 類型(支持型 Supportive、控制型 Controlling、指導型 Directive)中控制程度最高的一種。

### Q5. `sc-004` — 單選題

**題目 ID**: `sc-004`

難度: `medium` ｜ 建議作答時間分類: `agile_scenario` ｜ 版本標籤: `pmbok8` ｜ 原始 performanceDomain: `Governance` ｜ ECO domain: `BusinessEnvironment`

**題幹**

- EN: A project team is comparing several options and selects the one with the best financial return, without considering the project's environmental or social effects. According to the sustainability principle, what should the team do?
- 中: 專案團隊在比較數個方案時,選擇了財務報酬最佳的方案,卻沒有考量該方案對環境或社會的影響。依據永續性原則,這個團隊應該怎麼做?

**選項**

- (a) Proceed with the option that delivers the best financial return. / 直接採用財務報酬最佳的方案。
- (b) Choose the option with the lowest upfront cost to protect the budget. / 選擇前期成本最低的方案以保護預算。
- (c) Postpone environmental and social considerations until after delivery. / 將環境與社會層面的考量延後到交付之後再處理。
- (d) Balance social, environmental, and economic outcomes when comparing the options. / 在比較方案時,同時權衡社會、環境與經濟三方面的成果。 ✅ **正解**

**詳解**

這反映了「整合永續性(Integrate Sustainability)」原則。永續性強調三重基線(triple bottom line),也就是同時平衡社會、環境與經濟三個面向的成果。方案比較不應只看財務報酬,而應該綜合評估這三個面向。

### Q9. `gov-004` — 單選題

**題目 ID**: `gov-004`

難度: `medium` ｜ 建議作答時間分類: `agile_scenario` ｜ 版本標籤: `pmbok7` ｜ 原始 performanceDomain: `Governance` ｜ ECO domain: `People`

**題幹**

- EN: The project sponsor has not yet signed the project charter, but the project manager has already asked several team members to begin preliminary work and has committed budget to an external vendor. What is the most significant problem with this situation?
- 中: 專案贊助人(Sponsor)尚未簽署專案章程,但專案經理已要求數名團隊成員展開前期工作,並已對外部供應商承諾了預算。這個情況最主要的問題是什麼?

**選項**

- (a) The project manager is acting without formal authority, since resources should not be committed before the charter is approved. / 專案經理在沒有正式授權的情況下行動,因為在章程核准前不應動用資源承諾。 ✅ **正解**
- (b) The vendor should have been selected only after the project management plan was finalized. / 供應商應該等專案管理計畫定案後才選定。
- (c) The team members should have refused to perform any work without a signed contract. / 團隊成員應該在沒有簽約的情況下拒絕執行任何工作。

**詳解**
